## v0.24.0-balance1 · 스토리 미션 체감 압박/조작 밸런스 (2026-11-18)

- **스토리 미션 전용 적 출현 거리**를 iPhone 세로 화면 기준 약 245~310 게임 좌표로 조정해 기존 먼 화면 밖 출현보다 빠르게 전장에 접근하도록 했습니다. 해당 출현 적 HP를 12% 올렸고, 동시에 활동하는 적은 최대 20명으로 제한해 소형 화면 과밀도와 렌더링 부담을 억제합니다. 첫 임무에는 서로 다른 위치의 잔향 2명(일반 112 HP, 사격형 94 HP), 마레 동행에는 132 HP 수호 잔향 2명이 배치됩니다. 일반 적의 추가 출현은 첫 임무 7초, 마레 동행 10초 이후 시작하도록 완충 구간을 두어 처음부터 포위되지 않게 했습니다. 초반 일반 접촉 피해는 스토리 전투에서 6으로 낮추고, 돌진·보스 피해는 그대로 유지합니다.
- **정지 침식 예고**: 첫 임무/마레 동행/거울역 기록/설원역 중 한곳에 3.5초 이상 움직이지 않으면 현재 위치에 1.4초 동안 붉은 경고 원이 나타납니다. 원 밖으로 이동하거나 대시해 회피할 수 있습니다. 피하지 못하면 14 피해(기존 보호막·마레 방어를 정상 적용); 파동은 6초 쿨다운을 가지며, 성공한 회피 횟수는 결과 화면에 표시됩니다.
- 수호 잔향을 처리한 뒤 목적지에 도달하는 과정이 불필요하게 길어지지 않도록 **첫 스위치 180/-70, 마레 열차 문 -175/+80, 기록 귀환 문 -195/+90**(시작점 상대 좌표)으로 조정했습니다. 행동 목적과 승리 판정 자체는 유지합니다.
- 노아/아스터/벨라 지원 능력, 환자 호위와 생존/로그라이크·지휘 훈련·세이브 포맷은 변경하지 않습니다. 환자 호위는 자체의 1.6초 공격 경고를 사용하므로 정지 침식 효과가 중복 적용되지 않습니다.
- **테스트 대상**: 제자리 대기 경고·회피·피격, 스토리 전용 적 거리·적 수 상한, 나머지 모드 분리, 진행 기록 보존 및 기존 미션 목표 완료 테스트.
- **자동 조작 시뮬레이션(8개 시드)**: 제자리 고정은 첫 임무 0/8회 성공. 목표 위치를 알고 따라가는 조작 정책은 첫 임무 8/8회(평균 9.4초, 체력 64), 마레 동행 8/8회(평균 10.1초, 체력 62.5) 성공했습니다. 이 수치는 자동 조작이 목표 좌표를 아는 조건이며 사람의 평균 클리어 시간을 나타내지 않습니다.
- 수치는 첫 번째 코드 밸런싱 값입니다. 실제 아이폰 세로 기기 FPS, 평균 클리어 시간, 손 조작성은 사용자 실기 검증이 필요합니다.



## v0.23.0-mission1 · 스토리 전투를 미션 완료형으로 전환 (2026-11-18)

- 스토리 전투는 **정해진 시간이 지나면 성공하는 규칙을 폐지**했습니다. 임무 목표를 직접 달성하는 즉시 승리하며, 남은 시간은 **실패 제한시간**입니다. 가만히 있어도 자동 공격으로 버티는 것만으로는 승리하지 못합니다.
- **리제 첫 전투** (최대 45초): 회선을 지키는 잔향을 쓰러뜨린 뒤 금빛 **전원 스위치**로 접근해 1.1초 작동해야 성공합니다.
- **마레 첫 동행** (최대 75초): 열차 귀환로를 지키는 잔향 **2마리**를 쓰러뜨린 뒤 열차 문에 접근해 0.7초 머물면 성공합니다.
- **거울역 기록 회수** (최대 95초): 기존의 파란 기록장치(1.25초)를 회수한 후, 반대편의 금빛 열차 문에 접근해 0.7초 머물면 즉시 성공합니다. 기록만 회수하고 서 있으면 완료되지 않습니다.
- **설원역 분기 전투** (구조 신호 105초/격리 명부 95초): 기존 2개/1개 중계기 회수 요건은 유지하며, 마지막 중계기 작동 시 **바로 성공**합니다. 승리까지 기다릴 필요가 없습니다.
- **벨라 환자 호위**: 기존과 같이 환자를 직접 안정화하고 객차 탑승 시 즉시 완료하며, 중복 추가 변경 없음.
- 이동 방향 화살표·금빛 잠금/해제 목표 표식·행동 진행 링과 안내 문구를 추가했습니다. 목표 수호 잔향은 일반 적과 별개로 클리어에 필요한 상대입니다.
- 생존/로그라이크 전투와 90초 지휘 연습의 시간 처리, 보상, 영입·스토리 분기·저장 형식은 보존합니다. 새 저장 데이터 버전은 필요하지 않습니다.
- 실제 아이폰에서 장면별 플레이 시간/난이도/FPS와 터치 조작성의 장기 검수는 아직 완료하지 않았습니다.



## v0.22.0-patient1 · 벨라와 환자 호위 (2026-11-18)

- 제2장 설원역에서 **벨라를 정식 영입한 후**, 열차 이야기 화면의 **'벨라와 환자 구조'**를 선택해 독립 구조 임무를 시작할 수 있습니다. 기존 설원역 중계기/명부 임무와 기존 저장을 보존합니다. 설원역을 이미 완료한 저장도 열차에서 구조 임무를 시작할 수 있습니다.
- **환자에게 접근 → 3.2초 안정화(벨라의 온기 처치로 가속) → 환자가 일어나 걸어서 리제를 따라감 → 객차 문에 함께 도착하면 즉시 구조 성공.** 제한시간 100초, 환자의 HP가 0이 되거나 탑승하지 못하면 실패하고 이야기 전투 경계에서 재도전할 수 있습니다.
- 환자가 공격받기 **1.6초 전에 공격선/경고 링**이 보이고, 마레의 자동 보호 또는 환자 곁에서 사용하는 방패 카드가 피해를 실제로 막습니다. 벨라 '온기 처치' 카드는 환자 곁에서 환자 HP+24와 안정화 +1.65초를 제공합니다. 마레·벨라 카드는 첫 손패에 반드시 등장하며, 카드 시전자/비용/핵심 효과의 배치·초상화 가시성을 높이고 전체 설명은 펼쳐 볼 수 있습니다.
- 구조 성공 시 **환자 체력, 벨라의 실제 처치 횟수, 마레가 막은 피해 횟수, 출전 동료 명단**을 결과 화면에 표시합니다. 객차 이야기 화면에는 구조된 환자가 좌석에 앉아 있는 간단한 시각 연출과 벨라 후일담이 나타납니다. 구조 여부는 기존 story v4의 선택적 필드로 저장되므로 구 버전 백업과 호환됩니다.
- **제한:** 환자 캐릭터는 Canvas·CSS로 만든 임시 시각 연출이며 정식 SD 원화가 아닙니다. iPhone Safari 장시간 FPS·손가락 조작·스크린샷 전후 비교는 아직 기기 검증하지 않았습니다.

- 기록 장치는 월드상 파란 표식에 접근해 **1.25초 머무를 때만** 회수됩니다. 회수 전에 시간이 끝나면 임무 실패, 같은 전투 경계에서 재시작됩니다. 장치 회수 후에는 제한시간까지 생존해야 합니다.
- 갈림길은 **구조 신호 개방**(침식 +18)과 **봉인 유지·증거 확보**(침식 +5). 두 선택은 각각 다른 대화와 열차 후일담을 제공하고, 실제 출전 동료에 따라 짧은 의견과 유대 수치가 달라집니다. 선택·침식·기록 확보·유대가 **story version 3**에 저장됩니다.
- 기존 story version 1/2와 생존 탐험·조각·체크포인트·PWA 파일을 보존하며 구버전 로드는 v3로 이전합니다. 패배나 연습은 선택·보상을 확정하지 않습니다.
- 이는 **R3 첫 임무의 실제 플레이 가능한 이야기 확장**입니다. 새로운 전체 지역, 아스터·노아·벨라의 개별 합류 사건, 후속 결과가 반영되는 다음 역, 이리스·크로우 해금, 20~30분 완성된 장 전체, iPhone Safari 장기 플레이 QA는 아직 미완료입니다.



## v0.19.0-sdfix1 · 동료 SD 픽셀/투명도 깨짐 수정 (2026-11-18)

- 실제 iPhone 전투 스크린샷에서 **신규 동료가 흐릿하고 경계가 깨져 보이는 현상**을 확인하여 원인을 수정했습니다. 기존 3×3 스프라이트가 192×192(WebP)로 과도하게 축소되어 프레임당 **64×64**밖에 되지 않았습니다.
- 동일한 생성 원본에서 각 프레임의 배경과 캐릭터를 다시 분리하고, 연한 의상과 머리카락의 영역을 지우지 않도록 경계 연결 기반 투명도 마스크를 적용했습니다. 교체 아틀라스는 **384×384 AVIF(프레임당 128×128; 23KB)**입니다.
- iOS 및 최신 브라우저에서는 새 AVIF를 사용하고, 미지원 환경에는 이전 WebP를 안전한 표시용 예비 자산으로 남깁니다. 새 AVIF는 오프라인 PWA 캐시에도 포함합니다.
- 지원 효과의 원형 테두리가 얼굴 위에 그려지던 순서를 수정하고, 3인 파티에서 머리 위 텍스트가 겹치지 않도록 정리했습니다.
- 주인공·마레·카드 덱·저장 형식·전투 수치는 변경하지 않았습니다. 신규 동료 3명의 실제 iPhone 화면을 재확인해야 하며, 완전한 4방향 동작은 아직 후속 과제입니다.

## 기존 생존 탐험의 목표

경험치를 회수해 카드 조합을 준비하고, 각 역이 소거되기 전에 관리자를 쓰러뜨립니다. 세 역을 모두 복원하면 리제와 마레의 첫 장을 완료합니다. 귀환 조각은 영구 정비에, 탐험 일지는 다음 조합을 정하는 데 씁니다. 자세한 목표·자원·선택의 기준은 [GAME_DESIGN.md](GAME_DESIGN.md)에 있습니다.

## 구현한 내용

- 선택형 전투 목표 기억 등불: 18초 안에 원 안에서 1.2초 머물러 경험치·소거 위험 완화. 신규 투명 등불 아트·복원 링·화면 밖 방향 표시

- 준비/관리자 교전 목표와 도착 카운트다운, 소거 제한시간·환경 위험·이번 탐험 복원 수 구분
- 실제 이동·경험치 회수·카드 선택·대시 사용에 따라 진행되는 첫 탐험 안내
- 현재 카드에 연결되는 조합 후보와 남은 단계, 종료 이유별 다음 행동·유지/초기화 진행 안내
- 캠프 보상 위에 중복 노출되던 도움말 제거, 과거 복원과 이번 탐험 경로 구분

- 최근 10회 탐험의 결과·카드·유물·시너지 기록, 6종 도전 진행도와 다음 목표 안내
- 도전 달성 결과 안내와 백업/재접속 보존, 이전 누적 기록 호환

- 보스 체력 50% 이하의 2단계: 거울 지연 충격파·설원 대각선 교대·종착 강화 탄막
- 정예 불씨를 18초 안에 회수하면 체력 최대 12 회복·최소 3초 과충전

- 보스 처치 보상 3가지 중 선택, 역 사건과 함께 다음 역을 준비
- 신규 환경 소품 4종·역별 배치·과충전 오라와 모바일 효과 설정
- 주 칼날 장거리 명중 개선과 보이지 않는 이동 제한 제거

- 잔향 절단은 중앙 칼날 첫 적중 시 가까운 적 2명에게 연쇄 피해를 주고, 푸른 귀환은 대시 종료 지점의 적 탄환을 제거합니다.

- 빙결 시계는 일반 적을 잠깐 얼리고, 불멸의 랜턴은 2초 잔불 장판을 남깁니다. 카드 조합에 따라 길을 열거나 적을 유도하는 전투가 가능합니다.

- 역별 집단 습격: 망령 포위·늑대 협공·사격선과 추격. 등장 위치를 2초 예고하고 웨이브마다 진형을 회전합니다.

- 승리 시 획득 조각 +25, 실패·귀환 시 조각의 절반 지급, 탐험 ID로 중복 정산 방지

## 조작

아이폰: 왼쪽 조이스틱으로 이동, 오른쪽 대시, 공격 자동. PC: WASD/방향키, Space 대시, Escape 일시정지. 기본 대시 재사용은 3초이며 카드·유물로 단축됩니다. 대시 중 무적입니다.

## 구조와 실행

정적 HTML/CSS/JavaScript이며 서버·계정·결제·외부 분석 SDK가 없습니다.

- `js/data.js`: 카드·역·적·대사·유물·사건 데이터
- `js/store.js`: 버전 저장·정산·이전·복구
- `js/game.js`: 전투·카드 선택·역 이동·종료
- `js/render.js`: Canvas 렌더링·아틀라스 애니메이션
- `js/audio.js`: Web Audio 합성 음악·효과음
- `js/input.js`: 다중 터치와 키보드·입력 초기화
- `js/ui.js`: 화면·설정·백업·설치/업데이트 안내

로컬 HTTP 서버에서 루트를 열면 실행됩니다. PWA는 HTTPS 또는 localhost에서 확인합니다. 테스트는 Node 22 이상에서 `npm test`로 실행하며 추가 패키지 설치가 필요 없습니다. main 반영 시 테스트가 통과한 뒤 공개 파일만 GitHub Pages로 배포합니다.

## 자산과 운영

프로젝트에서 승인한 참고 이미지와 AI 생성 아트, 코드로 합성한 사운드를 사용합니다. 파일 출처는 [자산 기록](docs/ASSETS.md)을 참고하세요. 유료 재화·온라인 랭킹을 도입할 경우 로컬 저장만으로 신뢰성을 보장할 수 없으므로 별도의 서버 검증 설계가 필요합니다.

이전 정상 배포: `28c42946aa894912a23d73dc1ac0934e76454a02` (v0.3). 롤백은 이 커밋의 공개 파일로 새 릴리스를 만들되 **현재보다 새로운 서비스 워커 캐시 버전**을 부여합니다. 이전 서비스 워커로 단순 복귀하면 오프라인 클라이언트가 갱신을 인지하지 못할 수 있습니다.
