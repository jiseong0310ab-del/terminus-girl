# 종착역의 소녀 · Terminus Girl

[게임 실행](https://jiseong0310ab-del.github.io/terminus-girl/)

모바일 웹 고딕 판타지 생존 게임 프로토타입. 90초 테스트와 5분 생존전을 제공합니다.

## v0.3 — 눈 속의 랜턴

- 승인된 은청색 머리·남색 차장 제복·금장·랜턴 SD 시안을 실제 전투에 적용
- 눈 내리는 역 타이틀, 회화풍 승강장 돌바닥, 따뜻한 가로등과 눈발
- 시작 후 22초 조작·성장·대시 안내
- 카드별 시너지 요구 조건과 일시정지 화면의 현재 빌드 표시
- 캐릭터 이미지 로드 전에는 기존 캔버스 캐릭터 표시

왼쪽 조이스틱 이동, 오른쪽 대시, 공격 자동. PC는 WASD/방향키 이동, Space 대시, Escape 일시정지. 대시 재사용 3초, 대시 중 무적.

시간 절단 2 + 잔향의 분열 1 → 중앙 칼날 피해 +30%. 정지된 초침 1 + 시계의 파편 1 → 회전 파편에 둔화 부여, 둔화된 적에게 파편 피해 14 → 18.

## 검증 범위와 다음 단계

게임 로직 시뮬레이션, 실제 Canvas 이미지 렌더링, 이미지 로딩 실패 시 대체 표시, 카드 안내 및 빌드 요약 검증. 브라우저 UI·아이폰 Safari 실기·성능은 별도 확인 필요.

현재 SD는 단일 이미지에 이동·대시 효과를 적용합니다. 다음 미구현 작업은 방향별 걷기/공격 애니메이션, 적·보스의 일러스트 아트 통일, Safari 실기 피드백 반영입니다.

외부 라이브러리 없이 index.html과 assets/로 실행합니다. main에 반영하면 GitHub Pages 워크플로가 배포합니다. 탐험 기록은 현재 브라우저 localStorage에 저장됩니다.
