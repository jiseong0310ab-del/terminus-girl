# 종착역의 소녀 · Terminus Girl

[게임 플레이](https://jiseong0310ab-del.github.io/terminus-girl/)

삭제된 역을 거슬러 보호자를 찾는 리제의 고딕 철도 여정. **v0.15.0-rc1 파티 지휘 덱 + 기존 생존 탐험**을 공개 테스트합니다.

## R1 이야기와 첫 동료

- 짧은 탈취 프롤로그·거울역 도입 → 45초 단독 생존 → 마레 합류 → 75초 동행 생존 → 열차 대화.
- 마레 SD가 따라다니며 준비된 보호로 피해1회를 막고12초 뒤 다시 준비합니다. 합류 때 체력을 최대40 회복합니다.
- 대사/전투 경계 저장, 현재 전투 재시도, 지난 대화 다시 읽기. 기존 지갑/탐험 체크포인트/기록은 별도로 유지합니다.
- 이야기 시범은 생존 조각·도전·첫 장 승리로 정산하지 않습니다. 침식·역 처리 선택은 다음 단계입니다.

## R2 파티 지휘 덱

- 이야기 전투 전 **지휘 덱 편성**:12종 중8장, 손패3장. 마레 합류 후 리제/마레 전용 각각2장 이상, 보호/반격 추천 편성.
- **지휘 버튼(PC C)**을 누르면 전투가 멈춥니다. 한 장 사용 또는 닫기로 돌아가며, 최대3 지휘력은 전투12초마다1 회복합니다.
- 실제 피해를 마레·보호막이 막으면4초 동안 파동·절단을 강화하거나 반격을 사용할 수 있습니다. 레벨업의 기억 강화는 별도로 유지합니다.
- 마레 합류 후 **90초 지휘 연습**에서 강화된 적의 돌격·사격 예고를 시험하세요. 완료한 기존 이야기에서도 가능하며 이야기/보상을 바꾸지 않습니다.

## 기존 생존 탐험의 목표

경험치를 회수해 카드 조합을 준비하고, 각 역이 소거되기 전에 관리자를 쓰러뜨립니다. 세 역을 모두 복원하면 리제와 마레의 첫 장을 완료합니다. 귀환 조각은 영구 정비에, 탐험 일지는 다음 조합을 정하는 데 씁니다. 자세한 목표·자원·선택의 기준은 [GAME_DESIGN.md](GAME_DESIGN.md)에 있습니다.

## 구현한 내용

- 선택형 전투 목표 기억 등불: 18초 안에 원 안에서 1.2초 머물러 경험치·소거 위험 완화. 신규 투명 등불 아트·복원 링·화면 밖 방향 표시

- 준비/관리자 교전 목표와 도착 카운트다운, 소거 제한시간·환경 위험·이번 탐험 복원 수 구분
- 실제 이동·경험치 회수·카드 선택·대시 사용에 따라 진행되는 첫 탐험 안내
- 현재 카드에 연결되는 조합 후보와 남은 단계, 종료 이유별 다음 행동·유지/초기화 진행 안내
- 캠프 보상 위에 중복 노출되던 도움말 제거, 과거 복원과 이번 탐험 경로 구분

- 최근 10회 탐험의 결과·카드·유물·시너지 기록, 6종 도전 진행도와 다음 목표 안내
- 도전 달성 결과 안내와 백업/재접속 보존, 이전 누적 기록 호환

- 보스 체력 50% 이하의 2단계: 거울 지연 충격파·설원 대각선 교대·종착 강화 탄막
- 정예 불씨를 18초 안에 회수하면 체력 최대 12 회복·최소 3초 과충전

- 보스 처치 보상 3가지 중 선택, 역 사건과 함께 다음 역을 준비
- 신규 환경 소품 4종·역별 배치·과충전 오라와 모바일 효과 설정
- 주 칼날 장거리 명중 개선과 보이지 않는 이동 제한 제거

- 잔향 절단은 중앙 칼날 첫 적중 시 가까운 적 2명에게 연쇄 피해를 주고, 푸른 귀환은 대시 종료 지점의 적 탄환을 제거합니다.

- 빙결 시계는 일반 적을 잠깐 얼리고, 불멸의 랜턴은 2초 잔불 장판을 남깁니다. 카드 조합에 따라 길을 열거나 적을 유도하는 전투가 가능합니다.

- 역별 집단 습격: 망령 포위·늑대 협공·사격선과 추격. 등장 위치를 2초 예고하고 웨이브마다 진형을 회전합니다.

- 연속 격파로 공명 8 달성 시 랜턴 과충전: 6초 동안 공격 간격 25% 감소·경험치 수집 범위 50% 증가. 격파 사이 3초가 지나면 공명 초기화.

- 리제 4방향 대기·걷기 프레임, 대시·피격·사망 효과, 같은 화풍의 적·보스 아트
- 거울 유리역 → 침묵의 설원역 → 종착 승강장: 역마다 다른 적 구성과 보스 패턴, 1장 결말
- 일반 적 6종·정예 2종·보스 3종, 카드 16종·시너지 6종·유물 6종·사건 6개·기억 기록 6개
- 열차 거점, 영구 강화 3종, 마레의 기억과 대화, 복원 진행에 따라 바뀌는 기록
- 소거율에 따라 생성되는 예고형 위험 구역, 유한한 보스 제한시간
- 진행 중 탐험은 역 시작/복원 경계에서 저장, 다음 역까지 카드·유물 유지
- 승리 시 획득 조각 +25, 실패·귀환 시 조각의 절반 지급, 탐험 ID로 중복 정산 방지
- 저장 버전·정상 이전본 복구·내보내기/가져오기·v0.3 통계 이전
- 합성 BGM·효과음, 볼륨·섬광 감소·화면 품질 설정
- 홈 화면 설치용 manifest/아이콘, 완성된 버전의 오프라인 캐시, 사용자 선택에 따른 업데이트
- 90초/5분 전투 연습. 연습에서는 성장 조각을 지급하지 않습니다.

## 조작

아이폰: 왼쪽 조이스틱으로 이동, 오른쪽 대시, 공격 자동. PC: WASD/방향키, Space 대시, Escape 일시정지. 기본 대시 재사용은 3초이며 카드·유물로 단축됩니다. 대시 중 무적입니다.

계속된 전투가 아닌 **역 경계 체크포인트**로 재개합니다. 현재 역에서 얻은 카드와 조각은 그 역을 마쳐야 다음 체크포인트에 남습니다. 데이터 삭제·브라우저 변경·기기 변경 전에 설정에서 백업을 받으세요.

## 구조와 실행

정적 HTML/CSS/JavaScript이며 서버·계정·결제·외부 분석 SDK가 없습니다.

- `js/data.js`: 카드·역·적·대사·유물·사건 데이터
- `js/store.js`: 버전 저장·정산·이전·복구
- `js/game.js`: 전투·카드 선택·역 이동·종료
- `js/render.js`: Canvas 렌더링·아틀라스 애니메이션
- `js/audio.js`: Web Audio 합성 음악·효과음
- `js/input.js`: 다중 터치와 키보드·입력 초기화
- `js/ui.js`: 화면·설정·백업·설치/업데이트 안내

로컬 HTTP 서버에서 루트를 열면 실행됩니다. PWA는 HTTPS 또는 localhost에서 확인합니다. 테스트는 Node 22 이상에서 `npm test`로 실행하며 추가 패키지 설치가 필요 없습니다. main 반영 시 테스트가 통과한 뒤 공개 파일만 GitHub Pages로 배포합니다.

## v0.9.4 모바일·PWA 안정화

- 앱 전환·화면 잠금·브라우저 페이지 숨김 시 입력을 해제하고 전투를 수동 재개하도록 했습니다. 포인터 캡처 해제 오류도 안전하게 처리합니다.
- 카드 선택이나 역 사건 선택 후에도 사용자 탭으로 오디오를 다시 활성화합니다.
- Canvas의 실제 CSS 크기를 사용하고 최대 약 210만 픽셀로 제한해 메모리 부담과 불필요한 재할당을 줄였습니다. **실기 FPS·발열 달성률은 아직 측정하지 않았습니다.**
- 업데이트를 닫은 뒤 같은 알림이 화면 이동 때 재등장하지 않도록 했습니다. 전투 중 강제 업데이트를 막고 포그라운드 복귀 때 최대 분당 한 번 새 버전을 확인합니다.
- 동일한 저장 데이터를 반복 저장하지 않고, Safari/홈 화면 환경이 저장소를 공유하지 않을 수 있음을 안내했습니다.
- [아이폰 실기 테스트 절차](docs/MOBILE_QA.md)를 추가했습니다.

## v0.9.3 성장 선택·피해 균형 개선

- 첫 세 번의 레벨업에 공격 카드 후보 최소 1장 보장(강화 가능 카드가 남은 경우).
- 지금 선택하면 완성되는 시너지를 후보에 우선 포함해 무작위 선택의 막힘을 줄였습니다.
- 잔향의 분열 부가 칼날 피해를 70%로 조정하여 여러 칼날을 얻는 카드의 과도한 누적 피해를 줄였습니다. 주 칼날은 100%, 잔향 절단의 주 칼날 보너스는 +30%입니다.
- 사건에서 얻는 조각은 전액 즉시 지급되지 않으므로 `귀환 보상` 대신 `탐험 기억 조각` 문구를 사용합니다. 1장 승리 시 전액+25, 실패/귀환 시 절반 정산은 유지됩니다.
- [밸런스 가정 및 아이폰 테스트 질문](docs/BALANCE_NOTES.md)에 이론 계산과 실기 미확인 항목을 분리했습니다.
- 저장 형식·기존 탐험·보스 체력·타이머는 변경하지 않았습니다.

- 카드 선택 시 조합 진척과 즉시 발동하는 시너지를 미리 보여 주며, 황금 테두리로 구분합니다.
- 리제의 대시 잔상(섬광 감소/저화질 설정에서는 간소화), 보스 예고의 진행 표시를 보강했습니다.
- 선택형 업데이트를 통해 새 버전을 적용하며, 기존 저장 형식은 변경하지 않았습니다.

## 이전 안정화 변경

- 최신 기록을 덮어쓰는 오래된 탭의 저장을 탐지·차단하며 충돌 시 경고를 띄웁니다. 충돌한 탭에서 백업을 받아 보관하고 새로고침해 최신 기록을 확인하세요. 아주 짧은 간격의 완전 동시 저장을 원자적으로 직렬화하는 기능은 아직 없으며 실기 검증이 남아 있습니다.

## 검증과 남은 출시 조건

자동 테스트 193개: 카드/시너지 참조, 저장 손상 시 원본 보존·접근 및 용량 실패, 모바일 다중 입력, 감속·보스 처치 경계, 이전 기록, 대시·일시정지, 레벨업 대기열, 카드 소진, 유한한 종료 규칙·동시 사망, 3개 역과 체크포인트, 보상 중복 방지, PWA 경로·캐시 업데이트, UI 화면 흐름. 실제 Canvas로 3개 역의 스프라이트·예고·배경 렌더링도 확인했습니다.

자동 테스트는 실제 Safari 터치·오디오·발열·장기 성능·외부 테스터 검증을 대체하지 않습니다. 남은 조건은 [출시 체크리스트](docs/RELEASE_CHECKLIST.md)에 구분했습니다.

## 자산과 운영

프로젝트에서 승인한 참고 이미지와 AI 생성 아트, 코드로 합성한 사운드를 사용합니다. 파일 출처는 [자산 기록](docs/ASSETS.md)을 참고하세요. 유료 재화·온라인 랭킹을 도입할 경우 로컬 저장만으로 신뢰성을 보장할 수 없으므로 별도의 서버 검증 설계가 필요합니다.

이전 정상 배포: `28c42946aa894912a23d73dc1ac0934e76454a02` (v0.3). 롤백은 이 커밋의 공개 파일로 새 릴리스를 만들되 **현재보다 새로운 서비스 워커 캐시 버전**을 부여합니다. 이전 서비스 워커로 단순 복귀하면 오프라인 클라이언트가 갱신을 인지하지 못할 수 있습니다.
