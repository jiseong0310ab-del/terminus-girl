# v0.15.0-rc2 · 파티 지휘 덱 검증

2026-11-18. R1의 실시간 이동·자동 공격·대시/기억 강화를 유지하면서 실제 지휘 덱을 추가했다. R3 기록 확보·역 처리 선택·침식은 아직 구현하지 않았다.

## 플레이 진입

이야기의 전투 전 또는 첫 동행 완료 화면에서 **지휘 덱 편성**을 연다. 마레 합류 전에는 리제4+공용4, 합류 후에는12종 중 중복 없는8장을 고르며 리제/마레 전용 각각2장 이상 필요하다. 보호/반격 추천 덱과 역할 필터를 제공한다. 교체할 카드를 먼저 추가해9장 이상이 되면 줄일 수를 표시하고 저장을 막는다. 편성은 유효한8장일 때 경계에서만 저장하며 전투 중 바꾸지 못한다.

전투의 **지휘**(PC C)를 누르면 시간이 멈춘다. 손패3장 중 한 장 사용 또는 돌아가기를 선택한다. 지휘력은3으로 시작, 비용1~2, 전투12초마다1 회복한다. 사용한 카드는 버리고 빈 자리에 뽑는다. 더미가 비면 버림을 섞는다. 독립 PRNG와 경계 시드를 사용해 읽기/열기/설정/재접속으로 순서를 다시 굴리지 않는다. 전투 중간은 저장하지 않으며 패배/종료 후 현재 전투 시작으로 돌아간다.

마레 합류 후 **90초 실전 지휘 연습**을 열 수 있다. 기존 R1 완료 기록에서도 가능하다. 현재 기억 강화/덱을 가져오고 체력은 회복, 시간·격파는0으로 시작한다. 훈련은 이야기/지갑/탐험/도전/체크포인트를 변경하지 않는다.

거리의 단위는 게임 좌표다. 다음 수치는 초기 밸런스이며 영구 성장/최종 수치가 아니다.

## 자동 검증

`npm test`: **243/243 통과**. 기존 생존 원형과 R1 회귀를 포함한다. 전체 런타임 JS 구문 검사와 `git diff --check`도 통과했다.

- 12효과의 실제 범위·경계·비용·불가 조건·HP/보호 상한·장막 피해·경험치 큐·일반 연쇄 격파와 과충전 유지.
- 덱 보존/재섞기160회·별도 RNG·중복/미합류/최소 역할 규칙·초기 및 부동소수 회복 경계.
- 정지/레벨업/지휘/설정에서 시간·적·위험·지휘력·지원·연계 동결. 열린 메뉴 반복/설정/단축키/앱 숨김으로 손패 변경·몰래 재개 방지.
- 편성 저장 실패 롤백·다른 탭 충돌·백업 가져오기/재열기·합류 때 일회 기본 편성·진행 중 편성 차단·완료 기록의 훈련 재진입.
- 훈련 예고/혼합 적/등장 위치 점유 시 건너뛰기/적65상한/종료 직전 중단. 훈련 성공/실패/재시도에서 이야기·보상·기존 기록 불변.
- schema1/2→3 정상backup 먼저 이전·실패 시 primary 보호·정상 쌍 no-op·미래4 거부. 실제 직전57d84f2 store VM도 schema3 primary/backup을 읽지 못하고 저장을 거부해 원본 바이트를 보존했다.
- UI 실제 버튼 흐름, 유효하지 않은 선택/옛 버튼 재클릭/충돌 후 백업 설정/업데이트 중단 보호. 저품질·섬광 감소에서도 장막 링 유지, 시간0의 정지 렌더는 벽시계로 움직이지 않음.

## 자동 입력 정책 비교

`npm run qa:story`: 고정 시계·시드30개 ×5정책 =150회. 정상 엔진의 대사/성장/전투 경계로 진행한다. 직진/회피/기억 회수/초보 정책은30/30, 정지 정책은14/30 첫 동행 완료. 이야기 보상/기존 통계 변경 없음.

`npm run qa:commands`: 정상45초 단독 임무와 만남을 거친 체크포인트에서90초 훈련을 실행한다. 시드30×3정책×3편성=**270회**. 카드를 사용할 수 있고 상황이 적합하면0.8초 간격으로 검토하는 자동 정책이다. 전투 중 손패·지휘력·HP를 인위적으로 보충하지 않는다. 전투 전 편성 저장을 제외한 훈련 시작/성공/실패는 모든 저장 바이트가 같았다.

| 입력 정책 | 지휘 | 생존 | 평균 체력 피해 | 평균 사용 | 평균 보호 연계 |
|---|---|---:|---:|---:|---:|
| 이동·회피/회수 | 미사용 | 30/30 | 1.37 | 0 | 0 |
| 이동·회피/회수 | 보호 | 30/30 | 0.30 | 3.77 | 0.33 |
| 이동·회피/회수 | 반격 | 30/30 | 0.30 | 8.10 | 0.07 |
| 단순 방향 전환 | 미사용 | 30/30 | 7.50 | 0 | 0 |
| 단순 방향 전환 | 보호 | 30/30 | 2.40 | 5.57 | 0.77 |
| 단순 방향 전환 | 반격 | 30/30 | 3.30 | 8.30 | 0.10 |

기존 도입과 같은 초기 훈련은 피해가 거의 없어 덱 비교가 어려웠다. 훈련에 한해 등장 거리를 줄이고 일반 적HP1.4배, 출현 간격0.8→최소0.35초,12초 이후2초 예고의 돌격 포위/사격과 추격/수호자 구성을 추가했다. 원래45/75초 도입 난이도는 유지했다. 단순 정책의 피해 감소와 이동하지 않으면 실패하는 결과를 확인했다.

이 결과로 두 덱의 우열·사람의 체감 재미를 확정하지 않는다. 카드 효과의 입자도 전투 RNG를 소비하므로 같은 시드라도 카드를 쓰면 이후 전개가 갈라진다. 특히 자동 정책은 빠른 판단/조준 정보를 쓰며 보호 연계도 낮다. 다음 기록 확보 임무에서 정지/접근의 위험과 지휘의 사용 이유를 만들고 실제 플레이를 검수해야 한다.

## 공개 화면 및 남은 검증

코드 커밋 `36353ae`의 GitHub Actions44203942795 테스트/Pages 배포가 성공했다. 공개 Chrome에서 이전0.14 캐시의 새 버전 열기로0.15를 적용하고 다음을 확인했다.

- 원래 단독 임무에서 리제/공용8장 편성, 마레 카드 미합류 제한.
- 정상 엔진에서 이동/기억 선택으로45/75초를 완주한 시드1 체크포인트를 UI 백업 가져오기로 열고, 반격 편성 저장/새로고침 후 마레2장 선택 보존 확인.
- 보호 편성으로90초 훈련 시작. 실제3손패/비용/뽑기·버림 표시, 마레의 방패 사용 후 보호막1·지휘력2·뽑기4/버림1 및 새 손패 확인.
- 설정에서 C/Esc로 전투가 재개되지 않고 손패/회복까지12초 표시가 보존됨.
- 훈련을 UI로 종료한 뒤 내보낸 백업이 시작 전과 **완전히 같은 문자열**임을 확인. 원래 검수 프로필의 단독 임무/기존3회 기록도 UI로 복원했다.
- 이 과정에서 훈련 종료가 이야기 중단으로 표시되는 문구를 찾아 rc2에서 고쳤다. 편성의 미선택 카드가8장 선택 시 너무 어두워지고 먼저 빼야만 바꿀 수 있던 흐름도 rc2에서 임시 초과 편성→8장 조정으로 개선했다.
