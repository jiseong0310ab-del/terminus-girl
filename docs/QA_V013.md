# v0.13 목표와 첫 판 품질 검증

2026-11-17 · v0.13.0-rc2 (첫 사이클 rc1 포함).

## 구현과 자동 검증

전체 143개 테스트 통과. 새 14개는 다음을 확인한다.

- 준비/관리자/캠프/결과 목표, 음수 시간 방지, 실제 복원 수.
- 조합 후보의 남은 단계·안정적인 동률 처리, 조회가 RNG/전투/카드 후보를 바꾸지 않음.
- 캠프 재개·역 이동의 복원 수 보존, 동시 보스 처치/플레이어 사망은 복원/도전으로 기록하지 않음.
- 이동/경험치 회수/카드 선택/대시는 실제 성공한 행동만 학습 안내를 진행.
- 과거 복원과 이번 탐험 경로, HUD/일시정지의 목표·소거시간, 카드 후보, 종료 이유별 개선 행동.
- 캠프 보상 앞에 도움말이 중복 삽입되지 않고 도움말 화면에는 유지됨.

새로운 저장 형식을 추가하지 않았다. 기존 체크포인트의 역/단계로 복원 수를 재구성하고, 학습 상태는 현재 탐험에서만 사용한다. 연습·중복 정산·저장 실패·구버전/PWA·카드 대기열 회귀도 전체 테스트에 포함된다. 무작위 사건에서 카드를 받는 경우와 직접 출발하는 경우는 별도 시나리오로 검증한다.

## 공개 UI 확인

공개 원격 Chrome에서 기존 v0.12 캐시의 새 버전 열기를 통해 v0.13.0-rc1을 적용했다. 이미 한 번 귀환한 테스트 프로필에서 열차의 축약된 장 목표·새 탐험 출발/미복원 경로를 확인했다. 챕터 시작의 관리자 도착 3:01/역 소거 4:30/복원 0/3, 일시정지의 현재 목표, 귀환 확인과 결과의 실제 복원 0/3·지급 0·유지/초기화 안내를 확인했다. 이 검수에서 지급 0일 때의 개선 문구를 추가 보완했다. 새 사용자 3단계 안내와 카드/시간초과/사망/승리는 자동 UI 시나리오에서 검증했다.

증거: screenshots/v013-result.jpg. 원격 브라우저는 1363×936이며 모바일 실기 화면이라고 부르지 않는다. 실제 실행 시간은 약 1초인 즉시 귀환 시나리오로, 첫 역/장 완주나 게임 균형 검증은 아니다.

## 남은 범위

실제 아이폰에서 첫 조작부터 세 역 완주까지 목표를 이해하는지, 안내가 조작을 방해하는지, 성장/보상 선택이 재미있는지는 미확인이다. Safari/홈 화면의 터치·오디오·30분 성능·발열·오프라인/캐시 갱신과 외부 베타는 별도다. 기존 아트 방향과 전투 수치/보상 규칙을 이번 변경에서 유지했다.


## 선택형 등불 검증

두 번째 사이클은 12개 검증을 더해 전체 155개 통과. 등불 생성/고정 위치·부분 복원·회수/보상/카드 대기·만료/일시정지·보스/사망 취소·재개/다음 역·연습 제외·영구 재화 무지급을 실제 update 경로에서 확인했다. 복원 도형·화면 밖 방향·위험 안내 우선순위·실제 아트 로드/그리기 순서도 검증했다. 신규 에셋의 실제 알파와 13,574바이트 크기, 오프라인 목록 포함을 확인했다.

실제 원본 에셋으로 390×720 Canvas의 등불 기본/부분 복원(섬광 감소)/화면 밖 방향 상태를 렌더링했다(screenshots/v013-memory-lantern.jpg). 이 이미지는 장면을 구성한 렌더 검수이며 브라우저 조작/실기 플레이 캡처가 아니다. 선택 목표의 접근 위험과 보상 가치는 실제 첫 장 플레이에서 추가 조정해야 한다.
