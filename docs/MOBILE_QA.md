# 종착역의 소녀 · 아이폰 실기 점검표 (v0.9.4-rc1)

이 문서는 **실행할 테스트 절차**다. 여기 적힌 결과가 실제 아이폰에서 이미 검증됐다는 뜻은 아니다. GitHub Actions의 Node 테스트만으로 iOS Safari·홈 화면 모드·실제 발열·메모리는 검증할 수 없다.

## 0. 기록 보호
1. 게임 설정 → **백업 파일 내려받기**를 눌러 복사본을 보관한다.
2. 기존 기록이 있는 경우 현재 탐험의 역 경계 진행 상태를 확인한다.
3. Safari와 홈 화면에서 저장 기록을 공유하지 못할 수 있다. 서로 다른 실행 환경 사이에 기록이 자동 동기화된다고 가정하지 않고, 필요한 경우 백업 내보내기/복원 기능으로 옮긴다.

## 1. 터치 및 백그라운드 복귀
1. 90초 전투 연습을 열어 왼쪽 조이스틱을 움직이는 동안 오른쪽 대시를 누른다.
2. 조이스틱을 잡은 상태에서 홈 화면으로 이동하거나 화면을 잠근 뒤 돌아온다.
3. **합격:** 조이스틱이 중심으로 복귀하고 게임은 일시정지 상태다. 플레이어가 **계속 전투**를 누르기 전까지 적이 움직이거나 타이머가 진행되지 않아야 한다.
4. 전투 중 Safari 주소창 높이 변동과 가로·세로 회전을 시도한다.
5. **합격:** 터치 좌표가 어긋나지 않고 조이스틱·대시·일시정지 버튼이 가려지지 않는다.
6. 카드 선택 화면을 띄운 뒤 홈 화면에 갔다가 돌아와 카드를 선택한다.
7. **합격:** 카드 선택 후 전투가 진행되며 사용자가 음량을 켜 둔 경우 소리가 복구된다. 스피커/무음 모드에 따른 오디오 출력 정책은 기기에서 확인한다.

## 2. 오프라인 및 업데이트
1. 인터넷 연결 상태에서 게임을 한 번 열고 오프라인 준비 안내를 확인한다.
2. Safari 공유 메뉴 → 홈 화면에 추가를 통해 설치한다.
3. 홈 화면 실행, 종료 후 재실행을 확인한다.
4. 비행기 모드에서 이미 캐시된 게임을 열고 **90초 전투 연습**을 실행한다.
5. **합격:** 정적 리소스와 전투가 오프라인에서 정상 동작한다. 첫 설치 직후 완전한 캐시가 생성되지 않은 경우는 실패로 기록한다.
6. 인터넷을 다시 켠 뒤 새 버전을 배포하고 새 버전 알림이 나오는지 확인한다.
7. 전투 중에는 새 버전 설치 버튼으로 즉시 게임을 교체하지 않고, 열차·메뉴 등 안전한 화면에서만 수동 적용한다.
8. 업데이트를 무시/닫고 화면을 전환해도 같은 버전 알림이 반복해서 뜨지 않는지 확인한다.
9. **합격:** 새 버전 적용 후 저장 기록·설정·이어하기가 유지되고 오래된 JS/CSS와 새로운 리소스가 뒤섞여 오류를 내지 않는다.

## 3. 저장과 복원
1. 첫 역을 클리어하고 사건을 선택해 **진행 저장 · 열차에서 쉬기**를 누른다.
2. Safari를 종료하고 다시 열어 **탐험 이어가기**로 사건 선택 여부·카드·유물이 유지되는지 확인한다.
3. 백업 파일 내보내기 → 해당 백업 가져오기 → 기록·설정 일치를 확인한다.
4. 잘못된 JSON 파일로 가져오기를 시도한다. **합격:** 기존 저장 기록을 훼손하지 않는다.
5. 같은 Safari 저장 공간에서 두 탭을 연 뒤 한 탭의 기록을 변경한다. **합격:** 오래된 탭에서 저장 충돌 경고가 뜨고 새 기록을 덮어쓰지 않는다.
6. Safari와 홈 화면 기록이 분리된다면 동일 백업을 각각 복원한 뒤 별도의 진행으로 취급한다.

## 4. 장시간 플레이와 온도
- 한 번에 30분 이상 플레이하고 체감 발열·버벅임·멈춤·오디오 끊김·배터리 사용을 기록한다.
- 문제가 있으면 설정에서 **가볍게 · 발열 줄이기**를 선택하고 동일 구간을 비교한다.
- `자동` 화질에서도 Canvas 백킹 픽셀은 약 210만 개로 제한되며, 동일 크기의 중복 재할당을 피한다. 이는 메모리 완화책이지 60fps 보장은 아니다.
- 테스트 정보: 아이폰 모델 / iOS 버전 / Safari 또는 홈 화면 / 세로·가로 / 빌드 버전 / 구체적 상황 / 재현 여부.

## 출시 보류 기준
- **P0:** 저장 기록 손실, 게임 진행 불능, 반복 크래시.
- **P1:** 조이스틱 붙음, 버튼 가림, 장시간 심각한 성능 저하, 안전하지 않은 자동 업데이트.
- 아이폰 1장 완주, 저장·복원·오프라인·버전 갱신 확인 전에는 웹 v1.0 출시 완료로 표시하지 않는다.
