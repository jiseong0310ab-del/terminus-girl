# v0.9.3 전투 밸런스 점검 기록

기준: v0.9.3-rc1. 아래 수치와 판단은 게임 규칙과 코드에서 계산한 **설계 가정**이며, 아이폰 플레이어의 승률이나 실제 난도를 측정한 결과가 아닙니다.

## 레벨업 선택 규칙
- 처음 3회의 일반 레벨업에서, 공격 능력에 직접 연결되는 카드 `시간 절단`, `잔향의 분열`, `시계의 파편`, `꺼지지 않는 불` 중 아직 강화 가능한 카드가 있으면 최소 1장을 제시합니다.
- 이미 모은 카드와 결합하여 시너지가 **이번 선택으로 완성될 수 있다면** 완성 카드 중 하나를 제안합니다. 이 경우 공격 카드 보장과 별개로 적용하며 나머지 칸은 무작위 카드가 차지합니다.
- 모든 선택지는 중복 없이 3장 이내로 표시하고, 최대 레벨에 도달한 카드는 후보에서 제외합니다. 완전히 강화했다면 체력 회복 대안을 표시합니다.
- 무작위성이 남아 있으므로 특정 시너지의 완성을 보장하지는 않습니다.

## 다중 칼날 구성의 피해
- 기본 칼날 1개는 원래 피해의 100%, `잔향의 분열`이 추가한 칼날은 각각 원래 피해의 70%를 줍니다. 모든 칼날이 같은 적을 맞힌다고 가정하면 첫 추가 칼날의 순수 피해 증가량은 70%입니다.
- `잔향 절단` 시너지는 주 칼날의 피해를 추가 30% 높이며 부가 칼날 피해 비율은 변하지 않습니다.
- 이는 화면상 실제 명중률이나 전투 DPS를 예측하는 수치가 아닙니다.

## 보스 제한시간: 정적 계산
공격력이 증가하지 않은 리제의 공격력 17 / 발사간격 0.52초를 사용한 단순 계산입니다. 장애물·미스·피격·이동·프로젝트타일과 보스의 위치·카드 성장 등을 무시합니다.

| 역 | 보스 체력 | 출현 후 제한시간(약) | 기본 칼날이 전부 적중할 때의 이론 소요시간 |
| --- | ---: | ---: | ---: |
| 거울 유리역 | 1,000 | 89초 | 31초 |
| 침묵의 설원역 | 1,650 | 89초 | 50초 |
| 종착 승강장 | 2,400 | 99초 | 73초 |

이 가정만으로는 난이도가 적절한지 알 수 없어 **이번 패치에서는 보스 체력·공격 패턴·제한시간을 바꾸지 않았습니다.** 실제 플레이 중 느낀 명중률, 사망 요인, 카드 조합을 확인하고 다음 패치에서 조정합니다.

## 기억 조각 보상 설명
- 사건에서 얻는 조각은 즉시 최종 지갑에 지급되는 보상이 아니라 **현재 탐험의 보유 조각**을 증가시킵니다.
- 1장 완료 시 조각 전액과 추가 보너스 25개, 실패·귀환 시 조각의 절반을 정산합니다.
- 사건 문구를 실제 동작과 맞춰 `탐험 기억 조각 +N`으로 명시했습니다.

## 아이폰 테스트에 필요한 피드백
1. 첫 레벨업 3번 안에 공격 계열 카드를 선택할 수 있는가?
2. 카드와 시너지 조합이 너무 빨리 완성되거나 막히는가?
3. 어떤 역에서 보스를 처음 만나며, 보스를 잡을 시간이 충분한가?
4. 기본 칼날·다중 칼날·회전 파편·랜턴 등 서로 다른 빌드가 재미있는가?
5. 첫 패배/승리 후 기억 조각 보상 규칙을 이해할 수 있는가?

실제 아이폰 및 외부 베타 결과는 아직 확보하지 않았습니다.
